# AGENTS.md

Guidance for agents working in this repo. Keep additions to things an agent would
miss without help; verify before adding.

## What this is
- **ITK-SNAP** C++/Qt6 medical imaging app (this fork: `vhxjaouen/latimsnap`,
  default branch `llm-test`). Large CMake project requiring external **ITK, VTK,
  Qt6**. Uses git submodules (`Submodules/c3d`, `greedy`, `digestible`).
- Active experimental feature: **AI Assistant** chat panel (Ollama).

## Build & deploy (critical)
- **Compiling only works inside the Docker base image**
  `ghcr.io/vhxjaouen/latimsnap-base:latest` (see `Dockerfile`). The raw GitHub
  runner / host has no toolchain. Build is standard CMake + Ninja inside the
  container; repo is mounted at `/workspaces/latimsnap`.
- Deploy flow (automated in `.github/workflows/deploy.yml`):
  1. build in Docker
  2. `linuxdeployqt -no-strip -bundle-non-qt-libs` on the `ITK-SNAP` binary
  3. tar as **`ITK-snap-current.tar.gz`**
  4. `zip ITK-snap-current.zip ITK-snap-current.tar.gz`
  5. `rclone copy <file> pcloud:~/TEMP`
- The separate `.github/workflows/build.yml` is the upstream multi-OS (cpack)
  CI; don't confuse it with the Docker deploy workflow above.

## CMake gotcha (highest-value)
- Every Qt widget file must be registered in **three lists in `CMakeLists.txt`**:
  the `.cxx` list (~line 685), the `.h` list (~795), and the `.ui` list (~924).
  Missing one silently breaks the build.
- `.cxx` files `#include "ui_*.h"` — generated by `uic` at build time. Never
  hand-edit the generated header; rebuild via CMake.
- Network code needs **`Qt6::Network`** declared in `CMake/standalone.cmake`
  (lines ~114/131) and linked.

## AI Assistant (active work)
- Files: `GUI/Qt/Components/OllamaQAWidget.{h,cxx,ui}`; dock wired in
  `GUI/Qt/Windows/MainImageWindow.cxx:269-289` (Views menu toggle, starts
  hidden).
- Currently **Ollama-only**: `POST {server}/api/chat`, ND-JSON streaming,
  parses `{"message":{"content":...},"done":bool}`; history in `m_Messages`;
  view capture = `grab()` → downscale to ≤1024px → Base64 JPEG in `images`
  array. See `OllamaQAWidget.cxx:224-283`.
- **vLLM is an un-implemented goal.** vLLM speaks OpenAI-style
  `/v1/chat/completions` (SSE, different JSON shape) — that schema mismatch vs
  Ollama's `/api/chat` is the main integration hurdle. A backend abstraction is
  the likely next step; don't assume any vLLM code exists yet.

## Layout & test
- `GUI/Qt/Components/` = panels/widgets, `GUI/Qt/Windows/` = main windows/docks.
- Executable target is `ITK-SNAP` (`SNAP_BUNDLE_NAME`).
- Tests run via `ctest` (headless builds use `QT_QPA_PLATFORM=offscreen`/
  `xvfb-run`).
